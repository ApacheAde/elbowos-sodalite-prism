# Sodalite Prism

Full-colour **Python 3** neon laser-refraction arcade for [ElbowOS](https://x.com/ElbowOS).

Sweep a gold emitter. Rotate sodalite triangles. Bend the cyan beam into drifting gems. Chain hits for extra score.

Q / E aim · A / D rotate the selected prism · TAB select · R reset · ESC quit

## Play

```
pip install -r requirements.txt
python3 sodalite_prism.py --play
```

## Record a 9:16 reel

```
python3 sodalite_prism.py --record
```

Writes `/home/workdir/artifacts/SODALITE_PRISM_ElbowOS.mp4` (1080×1920, 15s, 30fps, h264).
